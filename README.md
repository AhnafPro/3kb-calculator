### A modern and cool-looking calculator all in a single line!
##### What's so special about it:
Nothing much honestly, it is a simple project but I tried to make the best out of as much as I can with my limited time. I kinda tried to make [this one](https://s3-alpha.figma.com/hub/file/905678057/579ed270-9231-4782-830d-bcca23f15d69-cover.png) but I sorta messed up with the buttons.
##### How it works=:
Just like any other calculator, enter some numbers put some operator between them and click "=", thats it.
##### How to use it:
1. Download the repo or clone it.
2. Go to ```/dist```.
3. Open ```uri.txt``` and copy the code.
4. Paste it in your browser's URL bar.
##### Building
```
npm install html-minifier-terser
node build.mjs
```
